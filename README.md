Resolución del ejercicio N°9 de la unidad 2 de programacion 2.
Simula una estación meteorológica que recolecta y consolida automáticamente las lecturas simuladas de diversos sensores para generar un reporte climático centralizado.

Las clases utilizadas son:

Sensor: Representa los dispositivos de medición con su respectivo tipo y la capacidad de generar valores numéricos aleatorios.
EstacionMeteorologica: Administra la colección de sensores y coordina la ejecución del reporte consolidado.
